# Buyer questions to ask AI engines

Run monthly, logged out, from one region. Record what each engine says, whether
it names stocksbrew, and which URLs it cites. Counts, not percentages, at this
traffic. If an answer gets a fact about us wrong, trace it to the page it cites
and fix that page (see `seo/context.md`).
